# ハコ譜メーカー 配布用

このリポジトリには、ハコ譜メーカーのアプリ（Mac 版・Windows 版）の配布ファイルだけを置いています。ソースコードは含みません。
アプリはこのリポジトリの「Releases」から自動でアップデートされます。

## ダウンロード（いつも最新版）

| | |
|---|---|
| **Mac 版** | [HakofuMaker-Mac.zip](https://github.com/pisukarii/hakofu-maker-releases/releases/latest/download/HakofuMaker-Mac.zip) |
| **Windows 版（インストーラー）** | [HakofuMaker-Setup.exe](https://github.com/pisukarii/hakofu-maker-releases/releases/latest/download/HakofuMaker-Setup.exe) |

- 上のリンクは、いつも一番新しい版を落とします。
- 一度入れたあとは、アプリが自動でアップデートします。
- 前の版は [Releases](https://github.com/pisukarii/hakofu-maker-releases/releases) にあります。
- Mac 版：zip を開いて「ハコ譜メーカー.app」をアプリケーションフォルダへ。初めて開くときは、右クリック →「開く」。
